# Character Asset Workflows

## Combined design checkpoint and anchor

Resolve identity and current styling before reusable assets.

- When styling is already specified, create one relaxed front-facing full-body design on a simple background.
- When one design layer is unresolved, create two to four same-pose, same-scale options and vary only that layer.
- Keep face, hair, body, linework, and palette behavior stable across comparison options.
- A clear option selection becomes the accepted anchor unless the user also requests revisions. Do not insert a duplicate confirmation question.

Include no unrelated props or text. Do not treat an unselected clothing option as an anchor.

## Core asset pack

For a reusable-IP build, create the turnaround and compact expression sheet in the same production stage after the anchor and current styling are accepted. Reuse one identity-and-styling lock for both and present them for one combined confirmation.

For a content-only request, the accepted anchor is enough. Do not force this pack before producing the requested content.

Do not create both assets for a provisional design and repeat them after outfit selection.

## Turnaround

Use front, side, and back views at the same scale and baseline. Keep clothing construction, hair length, highlights, accessories, body proportions, and shoes consistent. Avoid perspective poses and view labels unless requested.

## Expression sheet

Use a regular grid only when the user requests a set. Keep one character per cell, equal scale, no overlaps, and no accidental extra characters. Vary brows, eyes, mouth, gesture, body lean, and small emotion marks while preserving the face system.

Suggested compact set:

- greeting
- celebration
- shy or nervous
- surprised
- mildly angry
- crying or sad
- sleepy
- thinking or confused
- confident or proud

## Outfit, hair, and accessory exploration

Place first-time styling exploration inside the combined design checkpoint. Use this later workflow only when the user deliberately asks to change an already accepted design.

Change one design layer at a time. Preserve the same pose or turnaround layout across variants so the comparison remains useful. Regenerate only assets affected by the newly selected version.

For clothing references, copy construction-relevant details only. Simplify texture and seams to the target illustration style without losing defining cuffs, collars, straps, hems, or palette relationships.

## Companion IP

This branch is optional and disabled by default. Enter it only when the user explicitly requests a companion/pet IP or assigns an uploaded pet that role. Never present it as the standard next step after completing a person's IP.

When enabled, build the companion as an independent character with its own anchor, turnaround or multi-angle sheet, and expression set. Match the shared style profile while preserving species-specific proportions and signature features.

When both characters appear together, lock:

- relative height and body scale
- interaction distance
- shared line and color treatment
- each character's fixed traits

## Variant presentation

Label variants outside the generated artwork whenever possible. Avoid asking an image model to render comparison labels unless those labels are essential.
