# Infographic Workflow

## Decide whether an infographic is appropriate

Use an infographic for structured information such as:

- process or workflow
- timeline
- comparison
- framework
- checklist
- evidence or case summary
- data story
- conclusion and action guide

Use an ordinary illustration when the main need is emotion, atmosphere, or one visual metaphor.

## Lock the information first

Extract an exact manifest of required:

- titles and section headings
- names, dates, quantities, units, and labels
- process order and relationships
- chart values and source notes supplied by the user

Do not invent missing facts. Shorten long prose outside the image before locking it.

## Plan the page

Give each page one communication job and a top-to-bottom reading order. A normal page should contain about four to six readable information blocks. Add another page instead of shrinking text into an unreadable layout.

Default to a 3:4 portrait format for social knowledge cards when the user gives no format. Adapt to WeChat article width, cover, or landscape formats when requested.

## Integrate the IP

Use the character as a guide who points, demonstrates, compares, carries evidence, walks through a process, or reacts to a result. Keep the character secondary to the information and do not cover important text or data.

## Prompt fields

```text
CHARACTER LOCK: [fixed identity]
STYLE PROFILE: [line, palette, texture, composition]
PAGE GOAL: [one communication job]
FORMAT: [ratio and publishing context]
READING ORDER: [ordered blocks]
VISUAL STRUCTURE: [process, timeline, comparison, framework, checklist, data]
EXACT TEXT: [verbatim manifest]
DATA RULES: [values, units, order, relationships]
IP ACTION AND PLACEMENT: [supporting role]
AVOID: [invented text, false data, crowding, identity drift]
```

Generate and inspect pages individually. Repair only the page with incorrect text, data, identity, or layout.
