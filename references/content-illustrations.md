# Content Illustration Workflow

## Read for meaning

Identify:

- the central claim
- the emotional or logical progression
- concrete examples
- a conflict, change, decision, or conclusion
- ideas that benefit from visualization

Do not illustrate every paragraph. Select a small set of distinct visual beats that collectively explain the content.

## Plan before generating

For each image, record:

- source idea or passage
- communication job
- concrete scene or visual metaphor
- IP action and expression
- one to three essential props
- format and placement in the article

Use the user's requested count. Otherwise propose roughly three to five images for a normal article and adjust to content density.

## Make the IP meaningful

The IP should demonstrate, experience, compare, carry, inspect, repair, choose, or react to the idea. If removing the character leaves the image unchanged in meaning, rewrite the scene so the IP performs a useful action.

## Keep each image focused

- one main idea
- one dominant action
- limited props
- clear silhouette
- enough negative space for its publishing context
- no generic decorative technology icons unless the source requires them

Avoid repeating the same pose, reading scene, laptop scene, or pointing gesture across a series.

## Generation prompt fields

```text
INPUT ROLES: [identity anchor, style profile, content reference]
CHARACTER LOCK: [fixed traits]
ARTICLE IDEA: [one exact idea]
SCENE: [one concrete action or metaphor]
EXPRESSION AND GESTURE: [direction]
PROPS: [only essential objects]
FORMAT AND COMPOSITION: [ratio, subject scale, negative space]
STYLE PROFILE: [observable style rules]
AVOID: [identity drift, generic props, unwanted text, clutter]
```
